## ⚙️ Getting Started

### Clone the repository

    git clone https://github.com/skjha1808/Shubham-Portfolio.git

### Navigate to the project

    cd Shubham-Portfolio

### Install dependencies

    npm install

### Start the development server

    npm run dev

## 🏗️ Build

    npm run build
